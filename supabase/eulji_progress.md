# 을지대학교 크롤링 진행 상황 (1차 배치 완료)

이번 배치는 **대전캠퍼스(의과대학) + 전 캠퍼스 공통 교내장학금 제도** 범위만 다룸. **2026-08-02 사용자 확인**: 성남캠퍼스(간호대학·보건과학대학·바이오융합대학)와 의정부캠퍼스(간호대학·보건과학대학·자유전공학부)는 "나중에 이어서 할 일"이 아니라 애초에 **이 프로젝트 범위 밖**으로 확정함 — 을지대학교가 법적으로는 하나의 대학이어도 성남·의정부캠퍼스는 실제로 경기도에 있는 별개 지역 캠퍼스라(연세대 원주캠퍼스처럼 같은 학교 이름이어도 물리적으로 다른 도시), "대전 소재 대학생"이라는 이 프로젝트 취지에 안 맞음. 앞으로 을지대 관련 작업은 대전캠퍼스(의과대학)로만 한정.

## 캠퍼스 구조 확인 (중요, 처음 가정과 다름)

을지대학교는 대전/성남/의정부 3개 캠퍼스 체제. 대전캠퍼스에는 **의과대학 1개 대학만** 설치되어 있고(의예과+의학과 단일 학과 계열), 흔히 예상할 수 있는 "보건계열 단과대학"은 대전이 아니라 **성남캠퍼스**에 있음(보건과학대학: 임상병리학과·방사선학과·물리치료학과·치위생학과·안경광학과·응급구조학과·보건행정학과, 바이오융합대학, 미래융합대학 등). 대학원 과정은 전부 의정부캠퍼스에 편제.

즉 "대전캠퍼스 단과대학"으로 실제 존재하는 건 의과대학 하나뿐임 — 처음 가정했던 "의대 등 보건계열"이라는 복수형 표현과 달리, 대전에는 의과대학 외 추가 단과대학이 없음.

## GPA 관련 메모

- **2026-08-02 재확인 완료 — 공식 학칙 원문으로 확인함** (당초 15분 투입해도 못 찾았던 것을, 사용자 요청으로 이어서 파봐서 실제로 찾아냄). 경로: `eulji.ac.kr` 규정집 > 제2편 학칙 > 학칙(menuno=5699) > 임베드된 PDF `https://www.eulji.ac.kr/webshr/univ/download/rules/univrules.pdf`. curl로 원문 HTML을 받아 embed 태그 안의 실제 PDF 링크를 찾아낸 뒤 `pdftotext -layout`으로 텍스트 추출 — 을지대 사이트가 WebFetch로 바로 안 열려서(`Parse Error: Invalid header token`) User-Agent를 지정한 curl로 우회함. **제49조(성적)**에 고정값 표가 있음:

| 등급 | 평점 | 백분점수 |
|---|---|---|
| A+ | 4.5 | 95점 이상 |
| A0 | 4.0 | 90~94 |
| B+ | 3.5 | 85~89 |
| B0 | 3.0 | 80~84 |
| C+ | 2.5 | 75~79 |
| C0 | 2.0 | 70~74 |
| D+ | 1.5 | 65~69 |
| D0 | 1.0 | 60~64 |
| F | 0 | 59점 이하 |

**4.5만점제, A0=4.00 확인됨** — 기존에 잠정 적용했던 가정과 정확히 일치함. `data_eulji.sql`의 값은 재수정 불필요.
- 중앙 표에 나오는 GPA 조건은 거의 전부 "**직전학기**" 기준으로 명시되어 있어서 `min_gpa_basis`는 대부분 `'semester'`로 채움. 다만 "차세대의료인장학금"·"보건인"(제외)은 "전체학기 및 직전학기" 둘 다(AND) 요구하는데, 지금 스키마는 단일 기준(`semester`/`cumulative`/NULL=둘 중 하나)만 표현 가능해서 AND 조건은 표현 못 함 — description에 텍스트로만 남기고 `min_gpa_basis`는 비워둠(matching_gaps.md 13번과 같은 종류의 한계, 새 이슈로 추가 안 함).
