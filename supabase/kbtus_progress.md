# 한국침례신학대학교(KBTUS) 크롤링 진행 상황 (완료)

대전권 대학 병렬 크롤링 중 하나 (대전대·을지대와 동시 진행, 서로 결과 미공유). 이 파일은
작업 기록용 — 최종 SQL은 `data_kbtus.sql`, dedup 반영용 요약은 `kbtus_dedup_addendum.md`,
매칭 시스템 한계는 `kbtus_gaps_addendum.md` 참고.

## 결과 요약

- **신규 채택**: 45건 (배치1: 중앙 교내/교외 장학금 통합 페이지) — `data_kbtus.sql` 참고
- **로그인 차단으로 수동 확인 필요 항목**: 없음 (모든 게시판 정상 접속)
- **GPA 환산**: 4.5만점제 확인, 다만 등급별 고정값이 아닌 구간제 — 아래 "GPA 환산" 절 참고
- 소요 시간: 학교 규모가 작아(학부 10개 학과, 대학원 5개 과정) 예상보다 빠르게 마무리됨

- 학부 10개 학과: 신학과, 기독교교육학과, 청소년학과, 상담심리학과, 실용영어학과, 사회복지학과,

- **교내장학금**: `http://www.kbtus.ac.kr/kor/CMS/Contents/Contents.do?mCode=MN303`

  같은 성격 — 개별 신청기간 명시 없이 제도 자체를 표로 정리한 페이지.
- **교외장학금**: `http://www.kbtus.ac.kr/kor/CMS/Contents/Contents.do?mCode=MN310`
  국가장학금 계열(전국공통, 제외 대상)과 KBTUS 자체 운영 "외부장학금"(채플/성적향상/BTS/태성/
  지정·미지정) 계열이 한 페이지에 섞여 있었음.
- **장학공지사항 게시판**: `http://www.kbtus.ac.kr/kor/CMS/Board/Board.do?mCode=MN170`
  (총 499건) — 1페이지(2026-06-05~2026-07-30, 10건) 확인. 페이지네이션이 URL 파라미터가 아닌
  JS 기반으로 추정되어(page=2 요청 시 동일 내용 반환) 추가 페이지 확보를 시도했으나 실패 —
  대신 1페이지 표본만으로 판단(아래 "장학공지 게시판 확인 결과" 참고, 규칙 12 적용 시 대부분
  기존 dedup 항목과 겹칠 것으로 예상되어 큰 손실 아니라고 판단).

### 공통 자격기준 (중요)

교내장학금 페이지에 아래 문구가 전체 공통 각주로 붙어 있음(원문):
> "해당기준: 예배P, 직전성적2.5이상, 과락없음, 직전학점 기준이상 등 장학금지급규정 제8조(장학생의 자격) 참고"

즉 등록금지원형 교내장학금 대부분이 "예배출석 P등급 + 직전학기 평점평균 2.5 이상 + 과락(F)
없음"을 공통 최저기준으로 요구함. 이번 배치에서는 특수신분(목회자자녀/세가족/부부/교직원자녀
등) 계열 재학생 대상 장학금에 `min_gpa=2.5, min_gpa_basis='semester'`로 반영하고, 설명에도
"장학금지급규정 제8조 공통기준 적용"이라고 명시함. 다만 **순위 기반**(상위 5% 등) 장학금에는
적용하지 않음 — 실제 결정 조건이 GPA 절대값이 아니라 석차라서, 2.5를 넣으면 "2.5만 넘으면
된다"는 오해를 유발할 수 있어 과대매칭 방지 차원에서 비워둠.

## 2. GPA 환산 (하드 룰: 15분 예산 내 처리, 결과: 확인은 했으나 특이 구조)

공식 페이지(`mCode=MN140`, 학사안내 > 학사행정 > 성적평가 > 학부)에서 확인.

**4.5만점제인 것은 확인**되나, 다른 대전권 대학들(A+=4.5/A0=4.0 고정값)과 달리 **등급을
구간(range)으로 표기**하고 있음(WebFetch로 추출한 원문 표 그대로):

| 등급 | 평점 구간 | 등급 | 평점 구간 | 등급 | 평점 구간 |
|---|---|---|---|---|---|
| A+ | 4.31~4.5 | B+ | 3.61~3.9 | C+ | 2.61~2.9 |
| A0 | 4.16~4.3 | B0 | 3.31~3.6 | C0 | 2.31~2.6 |
| A- | 3.91~4.15 | B- | 2.91~3.3 | C- | 1.91~2.3 |
| D+ | 1.61~1.9 | D0 | 1.31~1.6 | D- | 1.0~1.3 |
| F | 0~0.99 | P/F | (Pass/Fail) | | |

이 표는 "등급→고정 평점" 방식이 아니라 "산출된 평점(소수점 단위 연속값)→등급 라벨"을
매기는 반대 방향 구조로 보임(다른 대전권 대학의 "A0=4.00 고정" 관행과 다름). **하드 룰에 따라
더 이상 파고들지 않고 여기서 중단** — 다행히 이번 배치의 장학금들은 "A0 이상" 같은 등급
조건이 아니라 전부 숫자 평점(예: "2.5 이상") 또는 순위(%)로 조건이 명시되어 있어서, 이 구간제
구조가 실제 데이터 입력에 영향을 주지는 않았음. `min_gpa` 값은 전부 학교 공식 페이지에 나온
원문 숫자(2.5)를 그대로 저장함 — 4.5만점 기준으로 확인된 값이라 신뢰도 높음.

**호성 확인 필요**: 만약 나중에 "A0 이상" 같은 등급 조건이 있는 장학금이 이 학교에서 추가로
발견되면, 위 구간표 때문에 다른 대학처럼 단순히 "A0=4.0"으로 못 박을 수 없다는 점 유의.

**2026-08-02 재확인**: 사용자가 3개 대학 GPA 표 전부 재확인을 요청해서 `mCode=MN140` 페이지를 다시
직접 열어봄 — 위 구간표와 정확히 동일하게 재확인됨(A+ 4.31~4.5 / A0 4.16~4.3 / A- 3.91~4.15 등).
4.5만점제 재확인 완료, 추가 조치 불필요.

## 3. 학과별 게시판 확인 (규칙 4 적용 — 소규모 학교라 전수조사 시도)

10개 학부 학과 전부 자체 서브도메인 홈페이지를 가지고 있음을 확인(신학과 `theology.kbtus.ac.kr`,
기독교교육학과 `educ.kbtus.ac.kr/educ`, 청소년학과 `youth.kbtus.ac.kr/youth`, 교회음악과
`music.kbtus.ac.kr/music`, 유아교육과 `childhood.kbtus.ac.kr/childhood`, 상담심리학과
`counsel.kbtus.ac.kr`, 실용영어학과 `english.kbtus.ac.kr/english`, 융합실용기악과
`instrumental.kbtus.ac.kr`, 사회복지학과 `welfare.kbtus.ac.kr`, 기독교문화학과는 별도 미확인).

실제 게시판 내용까지 확인한 곳(상담심리학과·실용영어학과·청소년학과)은 전부 학사행정
공지(자격증 발급, 분반 안내, 졸업자료 제출 등)뿐이고 **장학금 관련 게시글 0건** — 다른
대전권 대학(한밭대·배재대·목원대)에서 이미 확인된 "중앙 페이지에 데이터 집중, 학과 게시판은
학사행정용" 패턴과 일치함. 신학과·기독교교육학과·유아교육과·교회음악과는 게시판 존재만
확인(구조상 동일 패턴일 것으로 판단, 표본 확인으로 충분하다고 보고 전수 확인 생략).
사회복지학과 게시판은 서버 오류(HTTP 500)로 접근 실패 — 아래 "수동 확인 필요" 참고.

교회음악과 관련해서는 검색을 통해 "오르간 동문회가 2020년부터 후배 장학금으로 총 1,050만원
후원"이라는 정보를 발견했으나, 1인당 지급액·신청 방법 등 구조화된 정보가 전혀 없는 매우
비정형적인 소액 후원이라 DB에 넣지 않음(참고용으로만 기록).

  개발원), 2026 세종이도인재장학금(세종연구원), 농촌출신대학(원)생 학자금대출(한국장학재단),
  소아·청소년 당뇨인 「푸른빛 희망 장학금」, 서울인재대학장학금(서울미래인재재단 — 배재대
  배치2에서 이미 확인), 대학(원)생 학자금대출 이자지원(울산광역시 — 배재대 배치2에서 이미 확인)
- **국립국제교육원(NIIED) 슬로바키아/멕시코 정부장학생, 한미 대학생교류(WEST)**: 전국 공통

  찾지 못해서, 신규 발견일 가능성 있음(아래 "사용자에게 플래그" 참고)**.
- **2026 한국밀알선교단과 상천장학생 선발**: KBTUS 홈페이지 게시판에만 노출된 제목이라 정확한
  기관명·자격조건 확인이 더 필요해 보류. 신규 재단일 가능성 있으나 시간 예산상 깊이 파지 않음.

페이지네이션이 열리지 않아(2페이지 요청 시 1페이지와 동일한 내용 반환 — URL 파라미터 방식이
아닌 것으로 추정) 1페이지(약 2개월치)만 확인. 규칙2의 "마지노선+1개월" 기준을 엄밀히 채우지
못했으나, 확인된 10건 중 8건이 이미 dedup되어 있었다는 점에서 더 파고들어도 신규 발견
가능성이 낮다고 판단하고 중단함(규칙12: "포화 상태" 관찰과 일치).
