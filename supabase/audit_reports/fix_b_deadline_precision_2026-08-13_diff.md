## 꼭 짚어야 할 것 (사용자 보고용)

### 1. 구조적 문제 발견 — id=663 신한장학재단 "생활장학금"
DB의 신청 링크가 "생활장학금"이 아니라 완전히 다른 사업("법학전문대학원 장학사업")
페이지로 연결됨. 재단 홈페이지 전체를 봐도 "생활장학금"이라는 이름의 사업 자체가 존재하지
않음(현재 운영 중인 건 일반/유공자녀/자립준비청년/법학전문대학원/해외교환학생/리더육성
6개뿐). 날짜 문제가 아니라 **이 장학금 항목 자체가 유효한지 재조사가 필요한 수준** —
원문 재검색을 해서 이름이 바뀌었거나 폐지된 사업인지 확인 필요.

### 2. 기존 DB 텍스트 오류 수정 — id=1010 주소이전장학금(춘천)
기존 "매년 하반기(9월경), 2026년 미게시"는 틀렸음. 2026년 공식 공고(춘천인재육성장학재단
제2026-8호) 원문 확인 결과 주소이전장학금도 성적우수·특기장학금과 같은 공고, 같은
접수기간(2026-03-30~04-08)으로 접수받고 있었음.

### 3. 날짜 자체가 틀렸던 것 2건 발견 (시작일만 오차, 마감일은 맞았음)
- id=666 KT디지털인재 장학생: 시작일 01-14 → 01-05
- id=676 문화예술인재학부장학금(현대차 정몽구재단): 시작일 03-24 → 03-25

### 4. 백운장학회(id=1027~1035)는 충남이 아니라 전남 광양시 소속
작업 지시서에 "충남 소재 추정"이라 적었던 게 틀렸음 — 실제로는 광양시청 산하, 신청자격도
"광양시 1년 이상 거주". `eligible_region` 필드가 혹시 "충남"으로 잘못 들어가 있으면 이번
작업 범위 밖이라 손 안 댔음 — 별도 확인 필요. 접수기간도 기존 "08-01~08-31"에서 시작일이
실제로는 "08-03"으로 확인(1~2일 오차).

### 5. id=1054 제주 학자금대출이자지원 — 기존 DB 값의 근거를 못 찾음
기존 "2026 하반기: 07-01~10-08"이라는 값이 제주도청 원문 어디에도 없었고, 도청 페이지는
여전히 "2025년 하반기(07-01~09-30)" 정보만 게시 중. 값이 틀렸을 가능성이 있어 텍스트를
"근거 못 찾음"으로 수정하고 deadline은 채우지 않음.

### 6. id=1128, 1131 (안산인재육성재단) — 기존 DB 값이 검증되지 않은 추정치였음
"2026년 예정(공고 08-24, 접수 08-31~09-11)"이라는 기존 값은 실제 사이트에서 확인된 게
아니라 추정치로 보임(조사 시점 08-13 기준 아직 공고 전이라 검증 자체가 불가능). 값은 그대로
두되 "검증되지 않은 추정치"라고 명시하고 deadline은 채우지 않음 — 08-24 이후 재확인 필요.

### 7. 세종연구원 프로그램명 매핑 의심 — id=526,527,528,530,531
사이트에서 "모범장학생", "장애인 면학 장학생" 등 DB에 있는 이름의 개별 공고를 못 찾음(실제
사이트엔 "특기적성", "디딤돌 학자금대출" 두 프로그램만 확인됨). 기존 텍스트에 이미 있던
구체적 날짜(2026-05-06~07-10)를 근거로 deadline은 채웠지만, **DB의 세부 프로그램명 자체가
실제 사업명과 안 맞을 가능성**이 있음 — 이번 작업 범위 밖이라 텍스트는 안 건드렸고, 별도
확인 권장.
