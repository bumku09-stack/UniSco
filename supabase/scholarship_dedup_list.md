# scholarship 테이블 현재 등록 목록 (중복 확인용)

이 파일은 실행되는 코드가 아니라, `scholarship` 테이블에 이미 들어간 장학금을 추적하기 위한 기록입니다.
새로운 장학금을 크롤링/수집해서 넣기 전에 이 목록과 이름+기관 기준으로 대조해서 중복을 피합니다.

**중요**: 새 배치를 실제로 DB에 INSERT한 뒤에는, 이 파일에도 그 배치를 반드시 추가할 것 (안 그러면 다음 대조가 부정확해짐).

마지막 업데이트: 2026-08-02 (총 366건 — 대전대학교 45건 + 한국침례신학대학교 45건 + 을지대학교 20건 신규 추가, 3개 대학 병렬 크롤링이라 병합 시 이름+기관 기준 교차 확인 완료, 아래 각 대학 섹션 "교차 확인" 메모 참고. 사용자 확인 후 live DB 실제 INSERT 진행함).

**2026-08-07 갱신**: 대학 크롤링(366건)과 별개로 진행 중인 외부(재단/지자체) 장학금 발굴(`EXTERNAL_SCHOLARSHIPS_PLAN.md`)이 1~3차 배치로 296건(69건+227건) 추가됨 — **live DB 총 스콜라십 건수는 662건**. 외부 장학금 3차 배치(25개 기관, 227건)의 "이름|기관" 참고표는 이 파일 맨 아래에 추가함.

과거 이력 요약: 2026-07-27 실제 DB와 배치별 표 100% 일치 확인(총 117건 = 충남대 80건+KAIST 37건). 2026-07-31 두 차례에 걸쳐 `description`/`application_period`/`major` 등 필드에 남아있던 "확인 필요"류 표현을 전부 실제 정보로 교체하거나(5건 primary source 재조사) NULL 처리(39건, 실질 정보 없는 값)해서 사용자에게 노출되는 필드 기준 "확인 필요" 잔여 0건으로 정리(서비스 신뢰도 피드백에 따른 조치). 상세 경위는 git 히스토리 참고.

# 한남대학교 크롤링 (2026-08-01)

**GPA 환산 — 다른 대전권 대학과 구조가 다름(중요)**: 한남대는 등급을 +/0/- 세 단계로 나눔(다른 대학은 +/0 두 단계). 확정 환산표(4.5만점): A+=4.5, A0=4.3, A-=4.0, B+=3.5, B0=3.3, B-=3.0, C+=2.5, C0=2.3, C-=2.0, D+=1.5, D0=1.3, D-=1.0, F=0.0. **"A0=4.0" 관행을 그대로 쓰면 안 됨** — 한남대는 A0=4.3, A-=4.0임에 주의. **2026-08-02 재검증 완료**: 공식 학사안내 페이지(`hannam.ac.kr/kor/guide/guide_03_11.html`) 성적분류표로 직접 재확인 — 위 환산표와 정확히 일치, 그대로 유효함.

**사이트 접근성 문제**: 장학팀 홈페이지(`janghak.hannam.ac.kr`)가 장학금 개별 상세페이지 없이 이름만 나열하는 구조라 다른 대학보다 정보 확보가 어려웠음(약 80개 장학금 이름 확인, 검색으로 그 중 15개는 구체적 조건·금액 확보, 나머지 20개는 이름 기준 추정만 가능). 사용자 확인 하에 "장학팀 사이트 더 파보기"로 진행해서 얻은 결과.

## 배치 1: 교내장학제도 (대학 전체 대상, 35건, id 216~250)

**상세 확인된 것(15건)**: 레인보우(학생경력마일리지 7단계)/진리/자유/인돈/청림(신입생 수석계열)/성적우수/한남드림/희망드림/보람(봉사130시간)/면학(장애 본인·부모)/튜터장학금.
**이름 기준만 확인(20건)**: 어학인재/글로벌인재/성적향상/고른기회/농어촌학생/기초생활수급자·차상위(신입생)/검정고시출신자/외국인/해외선교사자녀/체육특기자/편입생/환경미화원자녀/동문자녀/장애인전형/영어우수/재외국민/고시/미술·문학우수자/모의UN경시/보훈/북한이탈주민/가족우대/교육자·교역자직계자녀/학생임원.

**2026-08-02 재검증 — 저신뢰 20건 중 대부분 상세 조건·금액 확인 완료**: 장학팀 홈페이지(janghak.hannam.ac.kr)는 여전히 개별 상세페이지가 없지만, **공식 발행 자료인 `2018학년도 한남대학교 정시모집요강`(장학금 안내 부록)**을 찾아서 대조한 결과 20건 중 17건의 정확한 지급 대상·금액을 확인함(2005년 개정 「장학금지급규정」 원문으로 1건 추가 확인). `data_hannam.sql`에 각 건마다 확인 출처·날짜와 함께 반영함.
